## 3. 关键裁决（R1–R5 + FQ，共 50+ 项，全部执行）

**架构**
- 调度：协作式 → **FreeRTOS 全量任务化**（ADR 0001 直接改写；认证影响评估不在范围）；群级预算废止 → 任务级周期/WCET/优先级预算。
- Flash：A/B 双槽 + 序号 + CRC + 上电体检（ADR 0002 补充）；擦写窗口禁读 bank2 + RAM 缓存。
- ISR↔任务交接契约：容量/溢出语义 + NVIC 优先级表 + 最坏延迟预算；看门狗关键模块表 + 拒喂阈值 + 复位原因；复位原因寄存器 + 上电封锁/杆空闲。
- 0x3C 快照：结果槽与运行态解耦（双槽轮换）+ 易失性说明；ADC 采样窗 257 ns vs 200 ns 待台架验证。

**故障模型（重构）**
- 故障字 **bit0 = 过流锁存硬件故障**（原 bit1 迁移；"系统自检失败"行删除）。
- 置位仅两条：上电自检（读锁存=1→清锁存→等 5 ms→重读仍=1）；0x3D 清除后重读仍=1。
- 0x3D 失败 → 应答 **0x20 执行失败**（ECSP 已有定义）+ 置 bit0 + 上传开启时补发 0x11；0x30 在 bit0 置位时 → **0x14 模块锁定**（主机 0x12 查询）。
- 运行中/电流异常态过流：不置故障字、不发 0x11、只发 0x3C（维持）。
- E-004：异常记录运行期仅 0x3D 清除，系统复位随运行态清零。

**协议**
- 0x11 门控 vs 会话例外 → **会话例外优先**；握手后状态统一"已连接"；主机不回传版本核对结果。
- 0x32/0x33 → **设置/获取触发模式**（0x00 直接触发 / 0x01 R波触发，字节语义不变）；「边沿触发」→「R波触发」全库改名。
- 上传模式：上电默认**关闭**（新 PRM-120），0x0F 开启，握手重置恢复默认；主机约定"版本核对后首命令 0x0F、之后不关闭"补入 ECSP §7.2。
- ECSP §8/附录 A 表 10-3：保护措施表与风险编号映射删除（用户裁定，不留记录）。
- 状态矩阵扩展覆盖通用命令；0x30 空闲停止幂等成功；(0,1500) V 外推精度 ±5% + 验收。
- 标定表：维持不可在线写，移出非易失写入失败保护范围。
- PRM-313 触发间歇维持 200–2000 ms（间歇内自检需 ≥5 ms 窗口，早前"改 0–2000"裁决已撤销）；停波时限判据=实测+安全分析上限。
- 出波前自检（后续补充裁决）：上电、0x30 受理启动（直接触发与 R波触发首轮前）、R波触发每个触发间歇内均执行锁存自检；失败置 bit0——受理时应答 0x14 拒绝启动，间歇内终止后续轮回空闲并发 0x3C、上传开启时补发 0x11。

**安全**：掉线后 R波触发最长 300 轮无人控制出波 → 登记为安全缺陷 [GitHub Issue #1](https://github.com/zhengjy926/pfa-psg/issues/1)（needs-triage），ambiguities PSG-19 回链。

**编号**：全量重排（无映射表）——PRM 各号段连续（159 个，孤儿 PRM-030/711 删除，新增 PRM-120/327/512）、SRS I/E/N 缺口收敛、ambiguities 编号链补全（A-01~A-16、PSG-01~19）。

**术语**：删「等待连接/等待触发/结算超时」；新增 R波触发、直接触发、触发模式、输出脉冲（MCU 级）/功率输出脉冲（功率级，50% 电平度量）、串级结算、串级超时、诊断电流、齐样等待、过流快照、半包、上传门控、上传模式、模块锁定；12 类 _Avoid 违规替换；术语表 123 词。
