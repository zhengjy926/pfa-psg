## A. 分层与接口蓝图（NQ8 授权重定义）

**分层保持五层名称，职责与任务映射重钉**（任务清单见 A-6）：

1. **应用层 app/**：板卡命令声明与载荷映射、ECSP 会话编排、故障上报与状态呈现 → 协议任务
2. **运行控制层 run/**：脉冲引擎（启停裁定/出波推进/杆控制）、电流结算 → 脉冲引擎任务 + 结算任务
3. **基础服务层 svc/**：标识记录（identity）、事务去重、故障字、任务监视 → 标识服务任务 + 协议任务（去重）+ 任务监视器
4. **板级执行层 bsp/**：sequence_io（HRTIM/杆/保护快路径）、adc_capture、uart、board_config → 无任务，仅接口
5. **MCU 驱动层 drv/**：uart/adc/dma/dac/comp/iwdg/flash/led/timebase/watchdog 全量抽象 → 无任务，仅接口

**接口文件清单**（★=新增/重命名）：
- drv/：`uart.h`、`adc_capture.h`、★`dac.h`、★`comp.h`、★`iwdg.h`、`flash.h`、★`led.h`、★`timebase.h`、★`watchdog.h`——统一 config/data/ops 静态实例模型（Q20 全量抽象，参考 Zephyr/TinyUSB/grblHAL，已在 embedded-layering-research.md 有调研）
- bsp/：`sequence_io.h`、★`psg_protection.h`（停波单所有者矩阵落点）、`psg_board_config.h`（+FreeRTOSConfig 登记）
- svc/：`identity.h`、★`dedup.h`、★`fault.h`、★`watchdog_monitor.h`
- run/：★`pulse_engine.h`、★`settlement.h`
- app/：★`psg_app.h`、`psg_ecsp.h`、★`psg_reports.h`、★`app_config.h`（Q19 集中登记：PRM-117、PRM-736、日志等级、拒喂阈值、队列容量）
- 共用：★`psg_event.h`——事件结构体 (类型, 运行序号, 群号, 串号, 单调时间戳, 有效样本边界)，归属裁定以硬件事实为准（Q16）

## B. 实时与安全时序

- **1.1 停波单所有者**：`psg_protection.h` 写矩阵——过流检出/过流锁存停波唯一由 HRTIM 硬件故障态完成（ISR 只捕捉证据不写输出）；复位模式「条件复位」→「锁存」（pinmap §2.4.3 固定配置改 + T-005 台架重验注记）；端口停波 = ISR 两条封锁写 + 事件入队，WCET 按 1.4 预算。影响：E-001/E-005/E-010、F-012、F-042、T-005、PRM-509/510/716、N-004、firmware-architecture.md 对应段。⏳ 端口 EEV 硬件联动：rm0440-facts.md 第 3 项可行则加"可选硬件联动"段落，不可行则明确接受 ISR 方案。
- **1.2 ADC 阶梯**：三级回退写入 current-settlement.md 与 firmware-architecture.md——L1 相位锚定（零改动，台架先验）；L2 采样时间 12.5→6.5 周期（134ns，不升时钟，T-007 复测）；L3 PLL P=6（115ns，⏳ 双 ADC 上限核实后作为裕量备选）。影响 PRM-705/708/710、T-001/006/007、F-035。
- **1.3 串级结算事件流（方案 A）**：TIMA ISR 只入队「串结束」事件到**结算任务队列**（几 µs 返回）；结算任务 `xQueueReceive(portMAX_DELAY)` 事件驱动；判定完成经任务通知唤醒脉冲引擎任务执行放行/F-041 终止；PRM-117 依据改"仅约束群级结算等待"，串级 1ms 截止为事件驱动。**修复跨文档矛盾**：firmware-architecture.md:10 串结束队列归属改为结算任务，与 current-settlement.md:9 一致。影响：F-038/F-040/F-041、PRM-117~119、PRM-305。
- **1.4 ISR 阈值/WCET**：`configMAX_SYSCALL_INTERRUPT_PRIORITY = 4` 登记入 psg_board_config.h 与 FreeRTOSConfig（0–3 预留不用）；每保护 ISR WCET <2µs（EXTI4/HRTIM1_TIMA/EXTI9_5 逐项登记）；端口停波最坏延迟公式 = 压栈 + 同级最长 ISR WCET + EXTI4 WCET，写入 F-012/T-005 验收。影响：PRM-726~730、N-004。
- **1.5 自检快速路径**：E-003 两分支显式化——锁存无效立即受理（快速路径）；有效则复位脉冲 + 挂起式等待（vTaskDelay/时基唤醒，禁忙等），5ms 计入 PRM-103 预算；5ms 期间新请求串行化。PRM-512 重复行已合并。
- **1.6 监视器数值化**：监视周期 100ms + 拒喂阈值连续 2 次逾期 + 零共享（只读原子推进标记，空闲健康态也推进）；最坏喂狗间隔 = 监视周期 + ISR 抢占上界，推导 <0.941s 写入 E-008；标识服务页擦除 24.47ms < 100ms 不误判。**事件组方案作为实现备选**写入设计文档（含"超时须 <0.941s、低频任务注销/注册"两条避坑）。新增 PRM-607（监视周期 100ms）/PRM-608（拒喂阈值 2 次）。
- **1.7 REP 硬件定界**：⏳ 待 rm0440-facts.md 第 1/2 项——通过则 PRM-715 改"按 PRM-304 派生（N-1）"、性质改派生、§2.4.1 重复计数更新使能、突发模式在群边界重载下一群参数（SINGLESHOT+REP 触发）；否决则回落软件计数（方案 B）并注明最坏 256 中断/串代价。影响：F-023、F-038、F-041、T-001~T-004、T-008。
- **1.8 DMA 归属（方案 A）**：DMA 缓冲固定最大尺寸（每路 2×256×2B=1KiB，两路 2KiB，RAM 不变），永久不改长度、只启停触发；HT/TC 降级为数据就绪提示（可合并/丢弃）；串边界 = TIMA 串结束锚 + ISR 内 NDTR 快照（每通道），样本归属公式 (串号, NDTR 区间) 统一覆盖跨群变 N/勘误 N+1/中止部分半区；删除"改长度+位置同步+清旧事件"重配置协议；台架验证 NDTR 同拍竞态。影响：F-037/F-041/F-043、current-settlement.md DMA 章节、firmware-architecture.md:10。

## C. 资源

- **2.1 RAM 预算**：firmware-architecture.md 新增静态 RAM 预算表（内核 3–4KB / 6 TCB / 任务栈 6×(512B–1KB) / 队列按容量×元素 / DMA 2KiB / 环形 2×1KiB / 快照 2×≤30B / 去重 ≤128B / ECSP 缓冲），总目标 **≤32KB**（PRM-602 一半余量）；`configCHECK_FOR_STACK_OVERFLOW=2` 金丝雀；每队列"产生率×消费延迟"推导式与 T-011/F-041 联立；map 文件核对写入 N-002 验收。
- **2.2 双槽快照**：环形双槽、第三次运行覆盖最旧槽；快照 = 结算完成的拷贝（不引用活数据）；0x3C 上报不清槽；与 0x31 复用 psg_reports 打包函数。影响 F-043~047、I-012、E-004。
- **2.3 去重 FIFO**：条目 = (序号 1B, 命令码 1B, 应答码 1B, 短载荷引用 ≤16B)，8 笔 ≤128B；发送完成出队；回绕按"最近 N 笔窗口"判定（FIFO 深度自然淘汰，形式化判据写入 dedup.h）；满时替换最旧 + 溢出计数。影响 I-007/I-012、PRM-027~029。
- **2.4 UART**：接收循环 DMA 零拷贝环形 ≥1KiB/路（2×PRM-011+余量），容量推导式（11.5KB/s 到达率 × 最坏服务间隔）与 T-011 联立；发送应答与上报分优先级（应答头插或双队列发送泵），上报仅在应答预算有余时放行，心跳/0x3C/0x11 计入核算；溢出行为写死（丢最旧→计溢出→重同步，时间戳随字节携带不受影响）。影响 T-011/I-008/N-003、PRM-011/115。
- **2.5 Bank2 布局**：ADR 0002 补——每记录独立槽区（页对齐）、槽序号+CRC 编码、上电体检只扫已用槽区；**裁定不做磨损均衡**（写入频率=产线一次+修复写回，理由入 ADR）；页轮换环列为未来按需升级路径（64 倍寿命，体检 +4–8ms ≪ PRM-116 500ms）。影响 E-009/I-024、PRM-601/739。
- **2.6 标定表**：PRM-407 依据补修订路径（外推不达标可增至 ≤256B，Flash 常量区富余）；0x34 最坏载荷（20 群×22B 校验 + 计划生成 + 标定查表/量化）WCET 核算入 PRM-102 预算登记；标定编译期常量表 + 分段线性预计算，运行期零插值。影响 F-024~026、T-001/006/009、PRM-102/407/408。
