# 参数登记表（PRM）

本文件是全部数值参数的**唯一来源**。其它文档只引用 `PRM-xxx`，不得另写数值。

- `性质` 列：`固定`（不可改）、`默认`（上电初值）、`可配`（协议可写）、`派生`（由其它参数算出）。
- `来源` 列指向基线原文（baseline 提交中的旧文件名与节号）或需求 ID；标 `Q-xxx` 的表示该值有争议，见 `OPEN_QUESTIONS.md`。
- 新增参数：追加到对应号段末尾，不重排既有 ID。

号段：`0xx` 物理层与帧 · `1xx` 时序与会话 · `2xx` 标识与版本 · `3xx` 序列与触发 · `4xx` 电流/电压/标定 · `5xx` 精度与判定 · `6xx` 系统非功能 · `7xx` MCU。
