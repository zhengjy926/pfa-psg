# 参数登记表（PRM）

本表登记项目采用的值、单位、范围、默认值和配置方式。行为与生效条件查 [对应规范](README.md)，字段布局和枚举语义查命令卡片。固定值、上电默认值、可配值和派生值由「性质」列区分。适用覆盖范围查 [ECSP §6.3](spec/ecsp-general.md#63-默认值与覆盖)。

| 号段 | 查询内容 |
| --- | --- |
| [0xx](#0xx-物理层与帧) | 串口、帧长、CRC、命令区和事务 |
| [1xx](#1xx-时序与会话) | 应答、握手、心跳、半包和结算预算 |
| [2xx](#2xx-标识与版本) | 地址、软件/硬件版本、SN、状态和故障字 |
| [3xx](#3xx-序列与触发) | 序列、触发、启停来源、杆与上电配置 |
| [4xx](#4xx-电流--电压--标定) | 电压档位、电流阈值和标定表 |
| [5xx](#5xx-精度与判定) | 误差、分辨率、杆延迟和保护时限 |
| [6xx](#6xx-系统非功能) | 资源、看门狗、指示和调度 |
| [7xx](#7xx-mcu) | 时钟、外设、DMA 和中断 |

按号段追加新参数，保留既有 ID。「依据」指向使用条款或派生来源。
