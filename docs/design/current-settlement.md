# 电流采集与串级结算设计

本设计落实 [SRS F-035 至 F-045](../srs/pulse-gen-firmware.md#24-电流采样齐样与结算) 的齐样、欠流判断和出波时序。ADC、HRTIM 与 DMA 的硬件绑定见 [MCU 映射](../hw/mcu-pinmap.md#2-外设配置)。采样窗口和最坏用时待台架验证。

## 采样与判定

1. 沿用 TIMB 触发两路 ADC，DMA 写入各自缓冲区。以已写入的数据为准，按通道和脉冲串归属消费样本。输出定时器的结束事件只用于确定脉冲串边界。
2. 有效样本一旦可用，就按通道累计该串的样本和个数。每个样本只处理一次。消费位置与串边界应可区分，缓冲区回绕、迟到数据和 DMA 溢出均应可检测。
3. 串末核对两路目标个数并完成阈值比较。截止前的工作仅包括收取末批样本、完成两路判定和发布下一串的许可。每一串的许可初始关闭，许可就绪后才可按原定时刻开始。结束当前运行时撤销该运行的待发触发，迟到样本不可开启下一串。
4. 每串结算时把各通道的样本和个数累计到所属群。群末完成最后一串的判定后，直接用累计值计算群平均。群级统计不需要重新遍历样本或为已齐样的脉冲串再次等待。计数和累加类型应覆盖 PRM-301、PRM-303、PRM-304 允许的最大序列。
5. 过流停波沿用硬件保护。中断捕捉故障来源和可用样本；阈值核对、错误日志及两路状态发布在任务上下文完成。

## 截止时间与验证

- 从**最后一个实际电流采样窗口**到 DMA 写入、样本消费、两路判定及下一串许可，测量并分段记录耗时。以 PRM-305 的最短串间隔做边界验证，同时核对杆切换是否留足 F-031 要求的导通等待。
- 覆盖最短非零脉冲、最长脉冲串、单极性和双极性、串末批次跨 DMA 缓冲区边界，以及通信和日志负载。核对实际 ADC 输入的有效窗口与采样精度，分别记录模拟采样窗口和样本写入延迟。
- 人为延迟末批样本或结算任务时，核对下一串确实未启动、运行终止且只记录错误日志。日志至少能定位该串、两路目标与实际样本数，以及失约发生在数据就绪还是判定阶段。
- 若在支持的配置上发生串级超时，按上述分段定位并修正采集、调度或结算设计，再用相同场景验证。核对群级结算满足 F-040 的独立预算。
