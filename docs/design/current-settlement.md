# 电流采集与串级结算设计

本设计落实 [SRS F-035 至 F-045](../srs/pulse-gen-firmware.md#24-电流采样齐样与结算) 的齐样、欠流判断和出波时序。「串级结算」「齐样」定义见 [术语表](../../GLOSSARY.md)。ADC、HRTIM 与 DMA 的硬件绑定见 [MCU 映射](../hw/mcu-pinmap.md#2-外设配置)。采样窗口和最坏用时待台架验证。

## 采样与判定

1. TIMB 触发参与出波通道的 ADC 采样。同一脉冲群内，每个参与通道每串目标样本数均为 `N`（PRM-304）。每路使用 `2N` 个 16 位样本的循环 DMA 缓冲区，前后半区各容纳一串。两路原始缓冲区总容量最大为 2 KiB。单极性只采集参与出波通道的电流。 [SRS F-023、F-036](../srs/pulse-gen-firmware.md) · [ST RM0440 §12.4.5、§12.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
2. DMA 半传输（HT）和传输完成（TC）中断交替发布半区就绪信息，标记通道及所属运行、群和串。定时器独立发布串结束事件。同一群内连续使用同一 DMA 配置。建立新的采集边界或修改 DMA 长度时，先封锁采样触发并确认搬运已结束，再同步参与通道的 DMA 位置和串号并清除旧事件。 [ST RM0440 §12.4.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
3. 串结束与各通道的就绪事件经队列交结算任务。收齐同一串的出波结束事件和各参与通道的就绪事件后，结算任务优先遍历该串的有效样本，计算各通道均值并完成欠流判定。每个样本只处理一次。下一串许可初始关闭，采集数据匹配且判定允许后才放行，由硬件按原定时刻开始。采集错误、样本数或半区归属不一致时禁止放行。到点没有许可则按 F-041 终止运行。结束运行时撤销待发触发，过期事件作废。
4. 每串结算时把各通道的样本总和和个数累计到所属群和本轮。群末完成最后一串判定后，直接用群累计值计算群平均。计数和累加类型应覆盖 PRM-301、PRM-303、PRM-304 允许的最大序列。
5. 中途停止或串级超时时，按终止判定时的 DMA 有效写入边界结算 `0x31`。合并已结算样本和边界内尚未结算的有效样本，每个样本恰好计入一次。部分半区的边界需由板级采集路径捕捉，强制中止后的 DMA 剩余计数无法单独确定该边界。 [SRS F-043](../srs/pulse-gen-firmware.md#24-电流采样齐样与结算) · [ST RM0440 §12.4.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
6. 硬件负责过流停波。中断捕捉故障来源和可用样本边界，跨串保留用于过流快照的最近有效样本；脉冲引擎任务完成阈值核对、错误日志和两路状态发布。 [SRS E-001、F-043](../srs/pulse-gen-firmware.md)

## 截止时间与验证

PRM-710 与 PRM-708 对应的 ADC 采样阶段约为 257 ns，PRM-307 和 PRM-308 的最短非零目标均为 200 ns。2026-11-18 批注给出的 IGBT 导通、关断延时估计分别约为 34 ns 和 282 ns。同一测量基准下，两者的差值约为 248 ns，可使功率输出脉宽相对驱动脉宽延长。以台架波形确认标定后的实际功率输出和 ADC 引脚有效窗口。[ST AN5346](https://www.st.com/resource/en/application_note/an5346-stm32g4-adc-use-tips-and-recommendations-stmicroelectronics.pdf)

- 从**最后一个实际电流采样窗口**到 DMA 就绪、结算任务取数、双路判定和下一串许可，测量并分段记录耗时。在最坏通信和日志负载下，核对最短 1 ms 串间隔的余量，以及 F-031 要求的杆导通等待。整串结算若余量不足，再评估在出波期间分批累加。
- 覆盖最短非零脉冲、`N=1` 和 `N=256`、单极性和双极性、HT/TC 交替和跨群改变样本数或参与通道。对齐 HRTIM 驱动、IGBT 功率输出、ADC 触发与 ADC 引脚电流信号，核对 ADC 输入的稳定窗口及 T-007 的采样误差。验证每个有效脉冲恰好产生一个有效样本，且每个完成半区归属正确的脉冲串。
- 核对 ST ES0430 §2.7.9，验证两次转换相隔超过 1 ms 后的首样精度，覆盖首串和跨串首样，重点覆盖 `N=1`。按勘误使用预转换时，预转换结果排除在有效 DMA 半区、样本计数和结算之外。 [ST ES0430 §2.7.9](https://www.st.com/resource/en/errata_sheet/dm00500968-stm32g471xx473xx474xx483xx484xx-device-errata-stmicroelectronics.pdf#page=17)
- 人为延迟末批样本或结算任务时，核对下一串未启动、运行终止、错误日志以及 0x31 的本轮电流读数。日志至少能定位该串、两路目标与实际样本数，以及失约发生在数据就绪还是判定阶段。主动停止覆盖本轮有部分样本、已触发但尚无样本、两轮之间等待的情形。过流验收覆盖当前半区未填满及下一串首样尚未写入的情形。
- 若在支持的配置上发生串级超时，按上述分段定位并修正采集、调度或结算设计，再用相同场景验证。
- 群级结算按 F-040 独立验收，预算按结算任务的任务级周期、最坏执行时间（WCET）与截止时间（PRM-117、PRM-119、PRM-118）核算。以最小群间隔和最坏通信、日志负载测量等待与结算，计入调度造成的延迟。记录两项最坏用时上界及其总和，并用较短的总用时上限减去该总和计算余量，验收以实测最坏用时及正余量为准。
