# 电流采集与串级结算设计

本设计落实 [SRS F-035 至 F-045](../srs/pulse-gen-firmware.md#24-电流采样齐样与结算) 的齐样、欠流判断和出波时序。「串级结算」「齐样」定义见 [术语表](../../GLOSSARY.md)。ADC、HRTIM 与 DMA 的硬件绑定见 [MCU 映射](../hw/mcu-pinmap.md#2-外设配置)。采样窗口有效性按「截止时间与验证」的三级回退阶梯落实，最坏用时待台架验证。

## 采样与判定

1. TIMB 触发参与出波通道的 ADC 采样。同一脉冲群内，每个参与通道每串目标样本数均为 `N`（PRM-304）。每路使用固定最大尺寸的循环 DMA 缓冲区（2×256×2 B = 1 KiB，两路合计 2 KiB，覆盖 `N` 上限 256），运行期间永久不修改 DMA 长度，只做触发启用与停止。单极性只采集参与出波通道的电流。 [SRS F-023、F-036](../srs/pulse-gen-firmware.md) · [ST RM0440 §12.4.5、§12.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
2. DMA 半传输（HT）与传输完成（TC）中断降级为数据就绪提示（标记通道及所属运行；同一半区重复事件可合并、可丢弃，不承载串边界）。串边界以 TIMA 串结束事件为锚：TIMA ISR 内对每个参与通道读取 DMA 剩余计数（NDTR）快照，样本归属按 (串号, NDTR 区间) 推导，统一覆盖跨群改变样本数、勘误预转换首样和中止部分半区三种情形。跨群变 `N` 或增减参与通道时 DMA 长度与配置保持不变，只启停触发，不再同步 DMA 位置或清除旧事件。 [ST RM0440 §12.4.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
3. TIMA ISR 只把串结束事件直接入结算任务队列（携带串号与 NDTR 快照，几 µs 内返回），各通道的就绪提示同队列交付。结算任务以 `xQueueReceive(portMAX_DELAY)` 事件驱动，无周期轮询。收齐同一串的串结束事件并核对各参与通道的 NDTR 快照后，结算任务优先遍历该串归属区间内的有效样本，计算各通道均值并完成欠流判定。每个样本只处理一次。下一串许可初始关闭，采集数据匹配且判定允许后，经任务通知唤醒脉冲引擎任务放行，由硬件按原定时刻开始。采集错误、样本数或归属区间不一致时禁止放行。到点没有许可则脉冲引擎任务按 F-041 终止运行。结束运行时撤销待发触发，过期事件作废。
4. 每串结算时把各通道的样本总和和个数累计到所属群和本轮。群末完成最后一串判定后，直接用群累计值计算群平均。计数和累加类型应覆盖 PRM-301、PRM-303、PRM-304 允许的最大序列。
5. 中途停止或串级超时时，按终止判定时的 DMA 有效写入边界结算 `0x31`。合并已结算样本和边界内尚未结算的有效样本，每个样本恰好计入一次。中止部分半区的有效样本边界沿用第 2 条的样本归属公式：以终止判定时刻的 NDTR 快照与该串的归属区间求交，强制中止后的 DMA 剩余计数不再单独确定边界。 [SRS F-043](../srs/pulse-gen-firmware.md#24-电流采样齐样与结算) · [ST RM0440 §12.4.5](https://www.st.com/resource/en/reference_manual/dm00355726.pdf#page=403)
6. 硬件负责过流停波。中断捕捉故障来源和可用样本边界，跨串保留用于过流快照的最近有效样本；脉冲引擎任务完成阈值核对、错误日志和两路状态发布。 [SRS E-001、F-043](../srs/pulse-gen-firmware.md)

## 截止时间与验证

PRM-710 与 PRM-708 对应的 ADC 采样阶段约为 257 ns，PRM-307 和 PRM-308 的最短非零目标均为 200 ns。2026-11-18 批注给出的 IGBT 导通、关断延时估计分别约为 34 ns 和 282 ns。同一测量基准下，两者的差值约为 248 ns，可使功率输出脉宽相对驱动脉宽延长。台架先确认标定后的实际功率输出和 ADC 引脚有效窗口；若 257 ns 采样窗不能整体落入最短非零脉冲的功率平台，按三级回退阶梯逐级激活（每级激活后全范围复测 F-035、T-007）：

- L1 相位锚定（零改动）：触发源不变（Timer B CMP3/CMP4，见 [MCU 映射 §2.4.4](../hw/mcu-pinmap.md#244-adc-触发)），只把采样窗中心对准因 IGBT 延时差加宽约 248 ns 的功率平台。台架确认 257 ns 窗整体落入平台后锁定本方案。
- L2 缩短采样时间（激活条件，不升时钟）：采样时间由 12.5 周期缩短为 6.5 周期，48.57 MHz 下窗宽约 134 ns < 200 ns，仅 L2 激活时改动 PRM-710。代价是 12 位精度下的采样裕量下降，激活时核对前端源阻抗并按 T-007 全范围复测。
- L3 提升 ADC 时钟（已核实不适用）：PLL P 7→6 得 56.67 MHz，但 ADC1+ADC2 同时采样上限为 52 MHz（DS12288 Table 66，Range 1 all ADCs operation, single ended, VDDA≥2.7 V），56.67 MHz 超限——双通道采样下不提升 ADC 时钟，维持 PRM-708=48.57 MHz（合规）。仅未来出现单 ADC 场景时 L3 可作备选。

- 从**最后一个实际电流采样窗口**到 TIMA 串结束、NDTR 快照、结算任务取数、双路判定、任务通知和下一串许可，测量并分段记录耗时；TIMA ISR 只入队并读 NDTR 快照，结算任务事件驱动、无周期延迟。在最坏通信和日志负载下，核对最短 1 ms 串间隔的余量，以及 F-031 要求的杆导通等待。整串结算若余量不足，再评估在出波期间分批累加。
- 覆盖最短非零脉冲、`N=1` 和 `N=256`、单极性和双极性、跨群改变样本数或参与通道，以及就绪提示（HT/TC）的合并与丢弃。对齐 HRTIM 驱动、IGBT 功率输出、ADC 触发与 ADC 引脚电流信号，核对 ADC 输入的稳定窗口及 T-007 的采样误差。验证每个有效脉冲恰好产生一个有效样本，且每串样本的归属区间（串号 + NDTR 快照）正确。台架验证 TIMA ISR 读 NDTR 快照与最后样本转换完成的同拍竞态，确认快照读值对归属区间边界无歧义。
- 核对 ST ES0430 §2.7.9，验证两次转换相隔超过 1 ms 后的首样精度，覆盖首串和跨串首样，重点覆盖 `N=1`。按勘误使用预转换时，预转换样本落在该串归属区间之外（NDTR 区间含此样本），按样本归属公式排除在样本计数和结算之外。 [ST ES0430 §2.7.9](https://www.st.com/resource/en/errata_sheet/dm00500968-stm32g471xx473xx474xx483xx484xx-device-errata-stmicroelectronics.pdf#page=17)
- 失约注入经编译期测试宏（发布版裁剪零残留）实现：人为延迟结算任务或丢弃某半区就绪提示，核对下一串未启动、运行终止、错误日志以及 0x31 的本轮电流读数，验证 F-041 终止路径。日志至少能定位该串、两路目标与实际样本数，以及失约发生在数据就绪还是判定阶段。主动停止覆盖本轮有部分样本、已触发但尚无样本、两轮之间等待的情形。过流验收覆盖归属区间未填满及下一串首样尚未写入的情形。
- 若在支持的配置上发生串级超时，按上述分段定位并修正采集、调度或结算设计，再用相同场景验证。
- 群级结算按 F-040 独立验收，预算按结算任务的任务级周期、最坏执行时间（WCET）与截止时间（PRM-117、PRM-119、PRM-118）核算；PRM-117 仅约束群级结算等待，串级结算为事件驱动（`xQueueReceive(portMAX_DELAY)`），无周期延迟。以最小群间隔和最坏通信、日志负载测量等待与结算，计入调度造成的延迟。记录两项最坏用时上界及其总和，并用较短的总用时上限减去该总和计算余量，验收以实测最坏用时及正余量为准。
