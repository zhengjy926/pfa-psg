# 脉冲引擎设计

## 运行状态归属

脉冲引擎任务统一裁定启停并更新运行状态。协议启动和端口启动共用启停输入源和启动门槛的判定规则。受理启动与 R波触发每个触发间歇内执行过流锁存出波前自检，失败置故障字 bit0：受理时按 0x14 拒绝启动，间歇内终止后续轮并按 F-047 发布结果，见 [SRS E-003](../srs/pulse-gen-firmware.md#5-异常与安全需求e-)。ECSP 任务执行公共请求检查和事务去重。调度任务将新请求经队列映射为脉冲引擎操作，并将业务结果映射为应答提交给 ECSP。 [固件架构](firmware-architecture.md) · [SRS F-002、F-004、I-007](../srs/pulse-gen-firmware.md) · [板卡命令状态矩阵](../spec/board-pulse-gen.md#命令状态矩阵)

端口停止与过流保护沿快速路径停波，脉冲引擎任务根据捕捉到的事件更新运行状态。端口停止与已检出的过流并发时，保留过流来源及该次运行的归属，按 E-001 处理。 [SRS F-012](../srs/pulse-gen-firmware.md#21-启停与触发) · [SRS E-001](../srs/pulse-gen-firmware.md#5-异常与安全需求e-)

比较器过流检出和独立过流锁存分别触发硬件停波。过流终止后停止杆对循环，保持停波时的杆驱动状态。脉冲引擎任务完成诊断并发布结果，`0x3D` 清除后恢复空闲杆状态。 [SRS E-001、E-005、E-010](../srs/pulse-gen-firmware.md#5-异常与安全需求e-) · [SRS T-005](../srs/pulse-gen-firmware.md#4-时序需求t-)

## 运行配置

脉冲引擎统一持有已提交的运行配置。符合受理条件的设置请求在空闲时整笔校验通过后一次提交。被拒绝时保留此前的配置和物理杆状态。运行期间使用已提交的配置，重复握手按 I-012 终止运行并使旧序列、输出电压和电流阈值配置失效。 [板卡命令状态矩阵](../spec/board-pulse-gen.md#命令状态矩阵) · [SRS I-012、I-013](../srs/pulse-gen-firmware.md#32-命令与载荷)

在配置阶段，序列参数与标定所需的输出电压齐备后，按 F-024、F-025 和 T-009 生成硬件出波参数。相关配置变更时重新生成受影响的参数，启动时使用与已提交配置对应的结果。`0x35` 读回 `0x34` 的原始设置值。 [SRS 出波](../srs/pulse-gen-firmware.md#22-出波) · [SRS T-009](../srs/pulse-gen-firmware.md#4-时序需求t-)

## 状态上报与新启动

`0x31` 返回查询时已发布的双通道状态、电流和已完成触发次数。运行产生 `0x3C` 时，脉冲引擎在确认序列完成或电流异常后保存该次结果的快照。快照存于 RAM 双槽、轮换保存最近两次结果，与运行态解耦，复位后丢失。 [SRS 状态呈现](../srs/pulse-gen-firmware.md#25-状态呈现) · [UART 入队与发送规则](uart-reception.md#发送)

主机可随时通过 `0x3C` 或 `0x31` 查询最近两次运行结果，新启动不依赖先取走上一运行结果。PSG 按启停输入源、运行状态、配置和过流联锁裁定启动。 [SRS F-003、F-004](../srs/pulse-gen-firmware.md#21-启停与触发) · [板卡命令状态矩阵](../spec/board-pulse-gen.md#命令状态矩阵)
