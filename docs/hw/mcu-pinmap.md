## 1 引脚分配

方向以 MCU 为参考，取值为「输入 / 输出 / 模拟 / 复用」。复用功能(AF)：只有 8 个复用引脚需要 AF，已按 STM32G474 通用映射填写（AF0/AF7/AF13），并与 CubeMX 参考工程的 `LL_GPIO_AF_13` 核对一致；其余引脚为「不适用」。「上电默认电平」指固件完成 GPIO 初始化后、输出脚所驱动的静态电平；非输出引脚（输入、模拟、复用）一律记「不适用」。归属需求在 [SRS](../srs/pulse-gen-firmware.md) 按 ID 定位，命令关联见 §3。

> 两个被「上电默认电平」列略去、但仍需实现的硬件事实：
> - 四个 EXTI 输入（PB4、PB6、PG7、PG8）配置为**内部下拉**（`GPIO Pull-up/Pull-down` = `Pull-down`）；
> - 复位到初始化之间是浮空窗口：复位后除调试脚外所有 GPIO 为浮空输入、输出数据寄存器为 0。安全相关输出（杆驱动 PD8–PD13、过流锁存复位 PG9）**必须由硬件上下拉兜底**，不能只依赖初始化后的「低电平」。

### 2.4 HRTIM1

时基基准 fHRTIM = SYSCLK = 170 MHz（PRM-707）。计时器 A/B 的预分频为 `MUL2`（PRM-713）：按 RM0440 的 `CKPSC[2:0]` 表，`MUL2`（`CKPSC = 100`）对应 **fHRCK = 2 × fHRTIM = 340 MHz**、分辨率 2.94 ns、最小 PWM 5.19 kHz，因此**计数时钟是 340 MHz，不是 170 MHz**。突发模式计数时钟取 `FHRTIM`（170 MHz，PRM-707），**不随计时器预分频放大**。ADC 时钟 = 48.57 MHz（PRM-708）。周期、突发预分频与 ADC 采样时间的换算值见 §2.1、§2.4.1、§2.4.5。
