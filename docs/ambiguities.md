# 文档疑点与待补项

本文件记录影响实现、验收或联调的资料冲突与缺口。条目给出当前来源、影响和需要确认的问题。确认后的行为写回对应规范。

## PSG 行为与验收

| 事项 | 现有依据 | 需要确认 |
| --- | --- | --- |
| 采样窗口与结算预算 | MCU 输出、实际电流波形和 ADC/DMA 样本就绪时刻各自独立。现有 [MCU 映射](hw/mcu-pinmap.md#244-adc-触发) 用 Timer B 比较事件触发采样。PRM-710 对应约 257 ns 的采样时间，已超过 PRM-307、PRM-308 的最短非零配置 200 ns，需要以 ADC 引脚实际信号核对。群级 PRM-117 的默认等待与 PRM-119 的上限相加恰好达到 PRM-118 的严格上限。 | 按 [串级结算设计](design/current-settlement.md#截止时间与验证) 验证采样精度、最短串间隔下的处理耗时和群级预算。[ST ADC 应用笔记 AN5346](https://www.st.com/resource/en/application_note/an5346-stm32g4-adc-use-tips-and-recommendations-stmicroelectronics.pdf) |
| 空闲电平和端口停止时序 | [MCU 映射 §2.4](hw/mcu-pinmap.md#24-hrtim1) 已规定两路空闲和故障时均为低电平。[§2.8](hw/mcu-pinmap.md#28-nvic) 已规定 PB4 的中断优先级。 | 台架测量初始化后的空闲及 HRTIM 故障输出电平。在通信负载下将 PB4 停止沿与 R 波、定时事件及过流分别对齐，核对停波后无新脉冲、过流记录保留且满足 SRS T-005。 |

## 整机待补项

本工程范围为 PFA_PSG。下列编号对应延期到整机或其它板卡工程处理的联调输入。

| 编号 | 需要输入或核对 |
| --- | --- |
| A-02 | 确认显控板链路的物理层配置，以及所有链路两端串口配置和最大帧长的一致性。 |
| A-03 | 提供中控板规范，覆盖其主机与从机角色、命令范围、故障位、物理层和符合性。 |
| A-04 | 提供回路阻抗采集与端口控制板规范，含命令范围、故障位、物理层和符合性。 |
| A-05 | 提供储能控制板规范，含命令范围、故障位、物理层和符合性。 |
| A-06 | 提供贴靠阻抗采集板规范，含命令范围、故障位、物理层和符合性。 |
| A-07 | 核对各节点的通用命令支持级别和不支持清单，供主机固化命令表。 |
| A-08 | 确认是否有产品级事件或周期上报，并提供命令码分配。 |
| A-09 | 提供板卡上电顺序、中控板开始握手的时刻和整机就绪或自检窗口。 |
| A-10 | 确认产品级应答时限覆盖项及取值。 |
| A-11 | 确认会话、心跳、掉线和上传模式是否有整机级覆盖。 |
| A-12 | 补充 PSG 之外的各从机期望软件完整版本与协议版本映射。 |
| A-15 | 确认整机的失败处置和异常上报策略。 |
| A-16 | 核对主机是否按节点查对应板卡的故障字位定义及处置规则。 |

## 已裁决

| 事项 | 写回位置 |
| --- | --- |
| 空闲时，杆对循环停用按杆选通，启用仅 AB 导通。故障字 bit1 置位或电流异常时六杆全断。 | SRS F-028、板卡协议 0x40/0x42 |
| 空闲时，合法的 0x30 停止请求回 0x00，保持空闲和杆选通。 | SRS F-012、板卡协议 0x30 和表 3-2 |
| 合法 0x30 请求同时遇到电流异常锁定与启停源不匹配时，按现有板卡矩阵返回 0x15。ECSP 主机收到此码后停止自动重试。 | SRS F-004、板卡协议表 3-2 |
| 空闲且故障字 bit1 为 0 时，0x3D 直接回成功。 | SRS I-021、板卡协议 0x3D 和表 3-2 |
| 0x3D 清除 bit1 后，物理杆状态立即恢复到 F-028 的空闲配置。 | SRS I-021、E-003；板卡协议 0x3D 和表 3-2 |
| 空闲过流不发 0x3C。开始监测前读取锁存输入电平，已有效时置 bit1；空闲时 bit1 置位拒绝启动。 | SRS E-002、E-003；板卡协议 0x11 与 §4 |
| 空闲允许 0x42 改杆并等待导通，运行时拒绝。杆对循环受理启动后先驱动 AB 并等待，边沿触发在等待后接受 R 波。同群的后续杆切换使用脉冲串间隔。 | SRS F-031 至 F-034；板卡协议 0x40、0x42 |
| 0x42 实际改杆时，导通等待完成后才回 0x00。 | SRS F-033；板卡协议 0x42 |
| 每串判断两路欠流，含群末最后一串；群平均仅供统计。任一路欠流即停止两路，待双通道数据填好后按上传模式发布一次。 | SRS F-038、F-039、F-042；板卡协议 0x3C |
| 到下一串原定开始时，上一串所需样本和判定未就绪即禁止继续出波。 | SRS F-037、F-041 |
| 过流中断捕捉 ADC 样本和硬件故障来源、提交内部事件。任务核对两路；ADC 未证实硬件过流时记错误日志，保留硬件记录并按上传模式上报。 | SRS E-001；板卡协议 0x31、0x3C |
| 合法的重复 0x01 触发固件内部重置，保留故障与非易失数据，回成功并保持就绪。单纯断链的 PSG 特有行为未定义。 | SRS I-012；板卡协议 §2 |
| 重复握手后，0x31 的普通电流读数和已完成触发次数清零，电流异常记录及其诊断电流保留。 | SRS I-012；板卡协议 0x31 |
| 欠流终止时，0x31 与 0x3C 填导致停波的同一串的两路均值；未判异常的通道填 0x00。 | SRS F-043、F-045；板卡协议 0x31、0x3C |
| 一次硬件过流事件中，可用单个有效 ADC 样本确认另一通道的过流，填 0x02。同一通道同时存在硬件过流锁存时优先填 0x03。 | SRS E-001、F-045；板卡协议 0x31、0x3C |
| 串级超时终止本次运行并只记错误日志，后续通过设计修正消除超时。 | SRS F-041；电流采集与串级结算设计 |
| 杆对循环未使能时，整个运行期间维持当前杆选通，故障覆盖规则按原条款执行。 | SRS F-030；板卡协议 0x40、0x42 |
| 通用命令区的扩展和新增应答码由 ECSP 通用规范定义。PRM-026 登记通用应答码范围。 | ECSP §3、§5.1；参数登记表 |
