本仓库描述脉冲信号发生板（PSG）固件及其 ECSP 接口。按手头的问题进入对应文档，用需求 ID、命令码、PRM 或信号名定位条款。

| 要查什么 | 从哪里开始 | 需要追溯时 |
| --- | --- | --- |
| 固件行为、交付范围、验收 | [固件需求](srs/pulse-gen-firmware.md) 中的 `F-`（功能）、`I-`（接口）、`T-`（时序）、`E-`（异常与安全）、`N-`（非功能） | 到板卡协议查命令码，到硬件映射查信号 |
| 本板命令、载荷、应答和状态许可 | [板卡协议](spec/board-pulse-gen.md#31-命令总表) §3；故障字见 §4，支持声明见 §6 | 到 ECSP 通用规范查公共规则 |
| 帧格式、CRC、通用命令、握手和重试 | [ECSP 通用规范](spec/ecsp-general.md#2-帧与编码) §2–§4；应答码见 §5，时限与覆盖规则见 §6 | 到板卡协议查本板差异，到参数表查数值 |
| 整机拓扑、每条链路的主从角色、地址与期望版本 | [产品通信配置](spec/product-cardiac-pfa.md) | 到板卡协议查某块板的命令和故障语义 |

| ADC 样本归属、串级结算和截止时间验证 | [电流采集与串级结算设计](design/current-settlement.md) | 到固件需求查验收行为，到 MCU 映射查硬件绑定 |
| 参数的值、单位、范围、默认值或配置方式 | [参数登记表](params.md)，按 `PRM-xxx` 搜索 | 结合引用该参数的条款判断适用场景 |

## 内容归属

SRS 定义本板的可验收行为。ECSP 通用规范定义各节点共用的线上语义，并规定允许覆盖的范围。板卡规范声明本板如何使用通用协议，产品文档声明各节点如何组成整机。MCU 文档记录信号到器件的绑定。各层若对同一行为给出不兼容的要求，先查疑点记录和已有裁决，再修改相关条款。

`PRM-xxx` 的取值以参数表为准。协议字段编码、枚举和示例字节留在命令卡片。术语定义留在术语表。

## 更新与核对

- 变更行为时保留仍有效的需求 ID 和命令码，核对相关需求、命令卡片与支持声明。删除作废条目或重排参数编号时同步更新引用。
- 变更已登记的参数时更新参数表，并核对引用处的范围、单位和示例。
- 新发现的冲突或缺口记入[文档疑点与待补项](ambiguities.md)。已有 GitHub Issue 时附编号。`[待补]` 表示缺少可引用的输入。
- 从仓库根目录运行检查。第二条校验已展开的 ECSP 示例帧，符号载荷的 CRC 用 `CRC` 表示。

```powershell
python tools/doc_check.py
python tools/frame_check.py --verify 'docs/spec/*.md'
```
