# 使用双 Bank 隔离固件与可写记录

PSG v3 采用双 Bank Flash 布局，将固件、中断向量和运行所需常量放在一个 Bank，运行时可写的非易失记录放在另一个 Bank，利用跨 Bank 读写并行维持擦写期间的调度。可写记录采用每记录独立、页对齐的槽区，区内 A/B 双槽，槽序号与 CRC 编码：写入新槽并校验通过后切换生效，擦写中掉电或校验失败回退旧槽；上电执行记录体检（读→校验→失败以默认值修复并写回），体检只扫描已用槽区而非整个 bank2。裁定不做磨损均衡：写入频率现实上为产线 0x03/0x05 一次性写入加罕见的上电修复写回，远低于 Flash 寿命上限，均衡逻辑无收益。页轮换环（槽序号单调递增、全槽区扫描取最新）列为未来按需升级路径，Bank2 富余空间可支持约 64 倍寿命，代价是体检增加约 4–8 ms 读扫，仍远小于 PRM-116 的 500 ms 上电预算。擦写窗口内禁止任何任务或中断读取 bank2（记录读路径在擦写期间走 RAM 缓存或拒绝），避免读停顿破坏看门狗与 HRTIM 时序。记录范围为软件版本、硬件版本、序列号和标定表：软件版本为编译期宏，硬件版本与序列号经 0x03/0x05 写入，标定表随固件发布、不可在线写。标识服务任务分步推进擦写，等待硬件完成时继续调度，完成后校验记录并按 ECSP 规则应答。通过选项字节和链接映射核对布局，在擦写期间验证关键中断和任务的时序。 [MCU Flash 配置](../hw/mcu-pinmap.md#01-flash) · [ECSP 应答时限](../spec/ecsp-general.md#61-命令应答时限) · [SRS I-024、E-009](../srs/pulse-gen-firmware.md)
