# 使用双 Bank 隔离固件与可写记录

PSG v3 采用双 Bank Flash 布局，将固件、中断向量和运行所需常量放在一个 Bank，运行时可写的非易失记录放在另一个 Bank，利用跨 Bank 读写并行维持擦写期间的调度。可写记录采用 A/B 双槽加槽序号与 CRC：写入新槽并校验通过后切换生效，擦写中掉电或校验失败回退旧槽；上电执行记录体检（读→校验→失败以默认值修复并写回）。擦写窗口内禁止任何任务或中断读取 bank2（记录读路径在擦写期间走 RAM 缓存或拒绝），避免读停顿破坏看门狗与 HRTIM 时序。记录范围为软件版本、硬件版本、序列号和标定表：软件版本为编译期宏，硬件版本与序列号经 0x03/0x05 写入，标定表随固件发布、不可在线写。标识服务任务分步推进擦写，等待硬件完成时继续调度，完成后校验记录并按 ECSP 规则应答。通过选项字节和链接映射核对布局，在擦写期间验证关键中断和任务的时序。 [MCU Flash 配置](../hw/mcu-pinmap.md#01-flash) · [ECSP 应答时限](../spec/ecsp-general.md#61-命令应答时限) · [SRS I-024、E-009](../srs/pulse-gen-firmware.md)
