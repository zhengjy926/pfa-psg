# PSG 固件评审验收用例

状态为评审稿。执行时记录固件 SHA、板卡版本、负载、测点、仪器带宽和原始波形。预期结果按同一提交的 [SyRS](../syrs/psg-subsystem-requirements.md)、[SRS](../srs/pulse-gen-firmware.md) 和协议判定。测点与软硬件分工见 [PSG-SyAS](../design/psg-subsystem-architecture.md#7-分配与集成验证)。待批准的容差、工况或安全限值仅记录实测结果，批准后再判定验收。

## 停止与保护

| 用例 | 需求 | 输入与判据 |
| --- | --- | --- |
| TC-STOP-01 | F-012-A、F-012-C | 协议启停源下在运行中发停止，检查双路后续脉冲封锁、回到空闲，未完成轮不计数。空闲停止按协议矩阵判定。 |
| TC-STOP-02 | F-012-B、F-012-D、T-005-A、T-005-B | 端口启停源下，在两通道各自有效时施加 PB4 负向过渡，分别测 PB4 到最后一路有效的 MCU 输出停止及 PB4 到两路功率输出停止。覆盖通信负载、紧邻后续置位事件、R 波和过流并发。确认后续脉冲封锁且过流运行归属保留。MCU 路径按数据手册适用条件判定，功率路径按 PSG-03 待批判据判定。 |
| TC-STOP-03 | E-001、E-005、E-010、T-005 | 分别激发比较器过流与独立过流锁存。对齐检测或锁存成立时刻与实际双路功率停止时刻，分别核对 ≤1 µs、≤10 µs，确认停止持续至 0x3D 成功清除，核对故障归属和杆状态。 |

## 脉冲采样与结算

| 用例 | 需求 | 输入与判据 |
| --- | --- | --- |
| TC-PULSE-01 | F-019、F-020、T-001 | 分别设置正负脉宽均为零、仅正非零、仅负非零和两路非零。检查非法组合拒绝和原配置保持，合法组合在对应通道输出并满足脉宽精度。 |
| TC-CUR-01 | F-035～F-038、T-007 | 以最短非零脉冲和边界配置出波，同步测实际功率波形、ADC 引脚有效窗口、采样触发与样本就绪。验证每个非零脉冲恰有一个同通道代表性样本、禁用通道零样本，联合核对 T-007。覆盖单极性、双极性及跨串边界。 |
| TC-CUR-02 | F-041-A、F-041-C | 以最短串间隔运行，并叠加通信和日志负载。记录样本就绪至许可生效的分段用时及余量，核对下一串按原定时间启动且符合 T-003。 |
| TC-CUR-03 | F-041-B、F-043-B | 分别注入缺样、判定迟到、许可迟到。确认下一串无输出、运行终止、诊断能区分失约阶段，0x31 仅用终止时已可读且属于本轮的有效样本。 |
| TC-CUR-04 | F-040 | 在最短群间隔下记录群级等待和结算上界，核对结算 ≤40 ms、总用时 <50 ms，且相对于最小群间隔留有正余量。 |

短脉冲和截止时间的测点与判据按 TC-CUR-01～TC-CUR-04 执行。样本归属、缓冲边界及预算的实板步骤见 [串级结算设计](../design/current-settlement.md#截止时间与验证)。

## 通信与标识

| 用例 | 需求 | 输入与判据 |
| --- | --- | --- |
| TC-COM-01 | I-007 | 在设备完成发送后丢弃应答并重传，分别覆盖已执行和业务拒绝的请求。检查原应答和无重复业务副作用。填满八笔后覆盖当前事务重传、顺序替换及 255→0 回绕。构造未确认八笔替换的回绕，验证主机先重建会话。同一键改换载荷应返回 0x03 且原应答仍可回放。重复握手及 0x07 跨复位恢复按协议判定。 |
| TC-COM-02 | T-010、I-028 | 空闲链路测两次发送完成时刻之差，插入业务帧确认基准刷新，持续业务期间检查独立心跳受抑。故障上报记录故障字新置位至 0x11 起始位的延迟，覆盖已有帧在途及上传关闭时的会话例外。心跳容差和上报延迟上限按 PSG-20 待批判据判定。 |
| TC-COM-03 | I-024、E-009 | 使用构建版本与旧 Flash 软件版本不同的镜像，检查 0x02 返回构建版本。分别注入硬件版本及序列号记录校验错误，核对相应默认值及修复记录，验证有效记录和镜像标定表可继续使用。 |

## 上电与复位

| 用例 | 需求 | 输入与判据 |
| --- | --- | --- |
| TC-RESET-01 | SYS-104、SYS-106、E-006、F-033 | 在批准的供电及复位工况内，覆盖冷上电、软件复位、外部或调试器复位、看门狗复位及欠压复位。同步记录供电、复位、双路实际功率输出、六杆状态和初始化完成时刻。核对初始化完成前双路无脉冲。保持 ECSP 未连接，核对正常初始化完成前六杆全通且进入空闲后保持，握手后以 0x43 核对默认选通为 0x3F。 |
| TC-RESET-02 | E-008 | 记录健康或正常等待时的最坏刷新间隔，核对 <0.941 s。保持其他功能可调度，逐个阻塞关键功能至配置的逾期判据，核对停止喂狗、实际复位和复位原因。 |
