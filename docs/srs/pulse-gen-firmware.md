# 脉冲信号发生板固件需求规格说明书

> PSG 固件交付范围与验收条款。线上字段查 [板卡协议](../spec/board-pulse-gen.md) 和 [ECSP 通用规范](../spec/ecsp-general.md)，硬件绑定查 [MCU 映射](../hw/mcu-pinmap.md)，量值查 [参数登记表](../params.md)。已知冲突见 [文档疑点](../ambiguities.md)。

## 0 查阅约定

适用项目为 psg-v3，器件与板级绑定见 [MCU 映射](../hw/mcu-pinmap.md)。术语按 [术语表](../../GLOSSARY.md) 使用。

| 需求 ID | 验收内容 |
| --- | --- |
| F- | 启停、触发、波形、杆控制、电流与状态 |
| I- | 接口符合性、板卡会话和端口分工 |
| T- | 时序、精度、延迟和通信时限 |
| E- | 异常处置、安全联锁、复位与持久化 |
| N- | 工具链、资源、调度与日志 |

同类新增条款继续编号，已有 ID 保持稳定。「应」「不得」是验收要求。「参数引用」列用于按 PRM 查值，「追溯」列用于查命令卡片、关联需求或硬件绑定。PC 表示用上位机收发协议帧核对，OSC 表示用示波器测量，其余验证方式按表内名称执行。

## 1 交付范围

本板固件交付启停、触发、出波、杆控制、电流采样与结算、异常判定、ECSP 从机和状态指示。通用命令支持情况见 [板卡符合性矩阵](../spec/board-pulse-gen.md#6-符合性矩阵)。整机、上位机、其它板卡和产线工装的实现由各自工程负责，整机接口见 [产品通信配置](../spec/product-cardiac-pfa.md)。
