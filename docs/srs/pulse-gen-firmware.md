| 记号 / 列 | 规则 |
| --- | --- |
| `F-` / `I-` / `T-` / `E-` / `N-` | 前缀含义：F 功能、I 接口、T 时序、E 异常与安全、N 非功能；三位数字，各族自 001 起 |
| 编号稳定性 | 保留现有编号，按需求类别追加新条款 |
| 需求表固定列 | `ID` ｜ `需求（可判定语句）` ｜ `验证方式` ｜ `参数引用` ｜ `追溯`，五列顺序不变 |
| `参数引用` 列 | 只写 `PRM-xxx`（可多个，用「、」分隔）；params.md 无对应项写 `—` |
| `追溯` 列 | 命令码（`0xNN`）、接口需求 ID、引脚（`§7`） |
| 要求级别 | 「应」「不得」表示验收要求，「可」「建议」表示允许选项或建议 |

## 1 范围与边界

| 项 | 结论 |
| --- | --- |
| 覆盖 | 本板固件：启停、触发、出波、杆控制、电流采样与结算、异常判定、协议从机、状态指示（自检本版不实现，见 I-023） |

| 单板调试版协议口 | USART1（PC4/PC5），被编译期宏选中时即唯一协议口（同一命令集、同一地址过滤、上报齐全） |
| 协议口选择 | 由编译期宏二选一：发布版用 USART2，单板调试版用 USART1；运行期不抢占、不切换 |
